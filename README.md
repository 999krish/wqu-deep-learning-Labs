# Deep Learning Fundamentals – WorldQuant University

A collection of hands-on deep learning projects completed as part of the WorldQuant University programme, covering neural networks, optimization, computer vision, sequence modelling and transfer learning.

## Projects

### Project 1 – Neural Network Foundations
- Explored linear functions, linear regression and gradient descent.
- Implemented multilayer perceptrons and nonlinear activation functions.
- Practiced tensor operations and fundamental PyTorch workflows.

### Project 2 – Perceptrons and Backpropagation
- Implemented a perceptron for binary classification and examined decision boundaries.
- Explored forward propagation, backpropagation and gradient computation.
- Built multilayer perceptrons using PyTorch and applied them to heart disease classification.

### Project 3 – Neural Network Training and Optimization
- Implemented feedforward neural networks for multiclass classification using the Yeast protein localization dataset.
- Explored optimization algorithms, loss functions and model training.
- Investigated overfitting, regularization and generalization.

### Project 4 – Deep Networks and CNN Fundamentals
- Implemented image classification models using the CIFAR-10 dataset.
- Compared multilayer perceptrons and convolutional neural networks.
- Explored deeper architectures, weight initialization and advanced training techniques.

### Project 5 – CNN-Based Image Classification
- Built convolutional neural networks using PyTorch for the Oxford-IIIT Pet dataset.
- Compared baseline and deeper CNN architectures for fine-grained classification of 37 pet breeds.
- Examined evaluation metrics, model performance and classification errors.

### Project 6 – CNNs and Transfer Learning
- Implemented CNNs from scratch for plant seedling classification across 12 species.
- Applied transfer learning using pretrained ResNet architectures.
- Investigated data augmentation and fine-tuning to improve image classification performance.

### Project 7 – Recurrent Neural Networks
- Explored the UCI Human Activity Recognition (HAR) dataset using smartphone accelerometer and gyroscope measurements.
- Trained vanilla RNN models to classify six human activities.
- Visualized hidden states and temporal representations, and investigated vanishing gradients and model limitations.

### Project 8 – LSTM, GRU and Time-Series Forecasting
- Prepared sequential datasets using sliding-window techniques.
- Implemented and compared RNN, LSTM and GRU models for temperature forecasting.
- Explored one-step and multi-step prediction, input sequence lengths and network architectures.

### Project 11 – Transfer Learning and Fine-Tuning
- Explored pretrained CNN architectures for image feature extraction.
- Applied transfer learning using pretrained models on the Caltech-101 dataset.
- Compared frozen feature extractors with fine-tuned convolutional layers and trained classifier heads.

## Technical Stack

- **Programming:** Python
- **Deep Learning:** PyTorch, Neural Networks, CNNs, RNNs, LSTMs, GRUs
- **Computer Vision:** Image Classification, Transfer Learning, ResNet
- **Machine Learning:** Gradient Descent, Backpropagation, Optimization, Regularization
- **Data Processing:** NumPy, Pandas, Matplotlib
