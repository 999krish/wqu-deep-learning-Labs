# WQU – Deep Learning Labs

A collection of practical deep learning and machine learning assignments completed as part of the WorldQuant University (WQU) programme.

## Overview

This repository contains Jupyter notebooks, implementations and experiments covering deep learning concepts and their applications.

The work focuses on implementing neural network models, processing data, applying machine learning techniques and exploring practical AI workflows.

## Running the Notebooks

1. Clone the repository:

   ```bash
   git clone https://github.com/999krish/wqu-deep-learning-Labs.git
   ```

2. Navigate to the repository:

   ```bash
   cd wqu-deep-learning-Labs
   ```

3. Install Jupyter Notebook and the dependencies required by individual notebooks.

4. Open the notebooks and execute the cells.
